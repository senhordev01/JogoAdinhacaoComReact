# JogoAdinhacaoComReact

Este projeto é um jogo de adivinhação feito com React onde o jogador precisa descobrir um número gerado aleatoriamente.

- Fácil: número entre 1 e 10
- Médio: número entre 1 e 100
- Difícil: número entre 1 e 1.000
- Muito Difícil: número entre 1 e 10.000
- Impossível: número entre 1 e 100.000

## Tecnologias
- React.js
- JavaScript

## Como Iniciar o Projeto
- git clone https://github.com/senhordev01/JogoAdinhacaoComReact.git
- cd JogoAdinhacaoComReact
- cd JogoAdivinhacao
- npm install
- npm run dev

## Funcionalidades
- Sistema de níveis
- Geração de número aleatório
